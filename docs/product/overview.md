# Product overview

## Purpose

Explora helps users find activities, open details, and save favorites for later. Favorites stay available offline.

## Core journey

1. Browse the catalog.
2. Search by title and/or filter by category.
3. Open activity details.
4. Save or remove a favorite.
5. Open the app again later. Favorites and their details stay available offline.
