# ADR-003: Simplified Technical English

- Status: Accepted
- Date: 2026-09-21

## Context

Long, idiomatic English increases cognitive load in agent replies, wiki pages, and JSDoc. ASD-STE100 defines clear writing rules for technical text.

## Decision

Write agent replies to the user, all `docs/` pages, and JSDoc with ASD-STE100 Simplified Technical English principles. Allow project technical nouns. Do not require full official-dictionary compliance.

## Consequences

- Text is shorter and easier to scan.
- Agents and humans share one writing standard.
- Some natural phrasing is restricted. Clarity comes first.
